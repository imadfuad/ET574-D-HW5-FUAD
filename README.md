# Student Score Predictor

**HW5 – Python GUI, Matplotlib, and Machine Learning Project**

## Project Overview

This project predicts a student's exam score based on study hours.

It uses Python, wxPython, Matplotlib, pandas, and a simple machine learning model called Linear Regression.

## Dataset Information

The dataset is in data.csv.

The dataset has two columns:

- study_hours
- score

The Iris dataset is not used.

## Setup Instructions

Install the required packages:

pip install -r requirements.txt

Run the program:

python main.py

## Usage Details

1. Open the program.
2. Type the number of study hours.
3. Click Predict Score.
4. The app shows the predicted score.
5. The chart shows the dataset and prediction line.

## Files

- main.py: main Python program
- data.csv: dataset
- requirements.txt: required packages
- README.md: project explanation
